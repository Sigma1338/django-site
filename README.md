## О проекте

FOOT73 — сайт любительской футбольной лиги, где можно посмотреть расписание
турниров, открыть карточку конкретного турнира и узнать подробности матчей.

## Что реализовано (Часть 1)

- **Главная страница** — баннер лиги, ближайшие турниры, блок «О нас», навигация по сайту.
- **Страница турниров** (`/tournaments/`) — список турниров с фильтрами и карточками.
- **Страница турнира** (`/tournaments/<slug>/`) — подробная информация о выбранном турнире.

## Что реализовано (Часть 2)

- **Вход и выход** (`/login/`, `/logout/`) — авторизация по e-mail и паролю, редирект на нужную страницу после входа.
- **Личный кабинет** (`/account/`) — доступен только авторизованным пользователям, показывает данные профиля.
- **Админ-панель** (`/panel/`) — доступна только администраторам: создание турниров через форму с валидацией дат, статистика по заявкам и список заявок со статусами.
- **Заявка на турнир** (`/apply/`) — форма с серверной валидацией; после отправки заявка сохраняется в базе и открывается страница подтверждения.
